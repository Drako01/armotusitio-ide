## Empezá en 3 pasos

1. **Instalá el IDE** desde la [última release](https://github.com/Drako01/armotusitio-ide/releases/latest).
2. **Instalá una IA** e iniciá sesión: [Claude Code](https://docs.claude.com/en/docs/claude-code) o [Codex](https://github.com/openai/codex).
3. **Abrí tu proyecto** y ejecutá **ArmotuSitio: Chat Harness** desde la paleta (`Ctrl+Shift+P`).
